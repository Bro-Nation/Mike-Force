# Sound Ranging

The server tracks functional `Land_vn_mobileradar_01_radar_f` buildables, shown in the build menu as Scouting Posts, as sound-ranging towers. Each functional tower has a global transmitter marker that remains until the building is removed. Black Horse engineers can also build a `vn_b_prop_vrc12` radio, shown in the build menu as a Recon Radio; it must be placed within the active area of a functional Fire Support Base. The buildables are configured in Mike Force's `mission/config/subconfigs/buildables.hpp`. Paradigm building-feature callbacks register and unregister towers, manage their markers, and attach the radio action; their definitions are in `server/configs/building_features.hpp`, `server/functions.hpp`, and `server/functions/building_features/soundranging`.

On each machine, the sound-ranging initializer installs a `Fired` event handler on local static weapons, including weapons created later. The handler forwards shots to the server, where the source is checked against the supported artillery list and functional towers within 12 km. The server records bearings from each tower to the shot. Shots within four seconds are grouped together, and detections expire after three minutes.

An alive Black Horse player within 5 m of a functional radio can request current bearings. The server validates the request and sends the data only to that player. The player's client creates local orange bearing markers. The player arms a guess with the map button, then a map click checks for supported enemy artillery within 25 m and, if found, places a local green confirmed-target marker. The confirmed target stays live while the radio is open, and is hidden with alpha 0 when the map closes so it can reappear immediately when the radio is opened again. Each armed click starts a 10-second cooldown, including misses; the remaining cooldown persists across map close/reopen and radio refreshes. The one-shot map-click handler is removed after the click or when the map closes. Bearing markers and confirmed-target markers are client-local and only visible in the radio map; they are cleared on map close or when the target is killed or deleted.

Supported static artillery matches the OPFOR mortar and D-44 classnames used by the mission's artillery sites. East-side vehicles inheriting from `vn_howitzer_base`, as well as rocket-artillery classname variants, are also recognized.

The marker deletion handler intentionally ignores sound-ranging markers so MACV/SYSTIM alerts are not triggered for the system's own map overlays.
